# Manal Hussain — Animated Developer Portfolio

A dark, futuristic, motion-heavy portfolio built with React, Vite, Tailwind CSS v4 and Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Included sections

- Animated Hero with developer illustration, parallax and floating tech labels
- About / stats
- Education timeline
- Skills toolkit and animated visuals
- Real project showcases with GitHub links
- Developer journey
- Career direction
- Contact / GitHub / LinkedIn / email
