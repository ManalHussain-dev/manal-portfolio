## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)

## ✨ Features & Architecture

- **Cinematic Dark Aesthetics**: Deep `#050508` background with subtle violet, purple, and cyan ambient lighting orbs and cyber-grid detailing.
- **Interactive Navigation**: Floating capsule header with scroll-spy active pill indicator, responsive mobile menu drawer, and glowing "Let's Talk" CTA.
- **Hero Showcase**: High-impact headline, framed developer IDE visual with floating tech badges, terminal details, and scroll indicator.
- **Filterable Skills Matrix**: Categorized across Frontend, Backend, Databases, Programming & App Development, and Tools.
- **Featured Projects & In-Depth Case Studies**:
  - **ReviewPilot**: Multi-protocol review management and analytics SaaS platform (REST, GraphQL, Webhooks, SOAP, MongoDB).
  - **Deadline Desk**: Task organization and deadline productivity dashboard (Node.js, Express, MongoDB).
  - **MediCore**: Mobile healthcare appointment scheduling concept (Flutter, Dart, Firebase).
  - **Coffee Shop Website**: High-end artisan coffee digital storefront (Responsive UI, CSS animations).
- **Interactive Case Study Modals**: Problem statement, solution, key features, architecture, development challenges, and learnings.
- **Learning Journey Timeline**: 6 core engineering pillars (Web Dev, OOP, DSA, Databases, API Dev, Mobile Dev).
- **Direct Contact Channel**: Direct email copy/compose (`manalhussain409@gmail.com`), verified links to GitHub & LinkedIn, and validated message form.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/ManalHussain-dev/manal-portfolio.git

# Enter project directory
cd manal-portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```
